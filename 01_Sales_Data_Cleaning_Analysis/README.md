# Sales Data Cleaning & Analysis

## Project Overview

This project focuses on cleaning and organizing a sales dataset using Microsoft Excel. The goal was to identify data quality issues, standardize inconsistent values, and prepare the data for analysis.

## Tools Used

- Microsoft Excel

## Work Completed

- Checked the dataset for duplicate records.
- Identified duplicate Order IDs and reviewed the related records.
- Standardized inconsistent date formats.
- Identified and corrected inconsistent city names.
- Standardized location names, including Vizag to Visakhapatnam.
- Applied consistent formatting to the dataset.
- Created summaries and visualizations to understand the sales data.
- Added a project information sheet to document the work.

## Key Learning

Through this project, I practiced working with raw sales data, identifying data quality issues, cleaning inconsistent values, and preparing a dataset for further analysis.
