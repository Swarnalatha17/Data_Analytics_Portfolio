# E-commerce Sales Dashboard

## Project Overview

This project focuses on analyzing e-commerce sales data and creating an interactive sales dashboard using Microsoft Excel. The project involved data cleaning, identifying duplicate records, standardizing location names, creating summaries, and presenting key sales metrics through a dashboard.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Charts
- Data Cleaning
- Data Visualization

## Work Completed

- Checked the dataset for duplicate Order IDs and reviewed duplicate records.
- Cleaned and standardized inconsistent city names, including Vizag and Bombay.
- Created Pivot Tables to summarize sales data.
- Calculated key performance indicators such as total sales, total quantity, and average order sales.
- Created charts and visual summaries for the dashboard.
- Designed an Excel dashboard to present important sales insights.
- Added a project information sheet to document the analysis.

## Key Results

- Total Sales: 26,285,550
- Total Quantity Sold: 936
- Average Order Sales: 21,905
- Dashboard metrics were calculated from the cleaned dataset.

## Key Learning

This project helped me practice data cleaning, Pivot Tables, KPI calculation, dashboard development, and presenting business data in a clear visual format.
